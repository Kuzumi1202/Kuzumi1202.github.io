面试考点：Lua 基础

发表于2025-10-08|更新于2026-11-13|游戏开发
|浏览量:

基础语法

pairs 与 ipairs

  • pairs(t) 用于遍历表中的键值对，不保证顺序；Lua 5.4 中可以通过 __pairs 自定义遍历。
  • ipairs(t) 从整数索引 1 开始依次访问，遇到第一个 nil 就停止，不适合有空洞的序列。
  • 表中赋值为 nil 表示移除该键，不能将它理解为可被遍历的普通值。

点与冒号

obj:method(x) 等价于 obj.method(obj, x)。冒号隐式传入 self，点调用需要显式传入。

元表与面向对象

Lua 可以用 table 保存状态，用函数和元表组织对象行为；语言本身没有内置的 class 关键字。

__index 与 __newindex

  • 读取表中不存在的键时，__index 可以指定后备表或处理函数。
  • 给表中不存在的键赋值时，__newindex 可以指定接收赋值的表或处理函数。
  • 没有 __newindex 时，赋值写入当前表，不会自动修改所谓的父表。
  • 表中已有键的普通读取和赋值不会触发上述后备逻辑。

rawget 与 rawset

rawget(t, key) 和 rawset(t, key, value) 直接读写表，不触发 __index 或 __newindex。编写元方法时可以用它们避免递归调用自身。

跨语言调用

Lua 与 C

Lua C API 通过栈传递值。宿主调用 Lua 函数时，将函数和参数压栈，调用后读取返回值；Lua 调用已注册的 C 函数时，C 函数从栈中读取参数并压入返回值。

Lua 与 C#

xLua、ToLua 等绑定框架封装 Lua C API，并处理托管对象映射、类型转换及生命周期。C# 对象并非直接作为原始对象放入 Lua 栈，框架需要维护对应的桥接表示。

以 xLua 为例，可以通过生成绑定代码减少反射调用，通过委托或接口映射访问 Lua。实际开销还包括参数转换、跨边界调用和内存分配，应减少高频细粒度调用。

垃圾回收

Lua 使用自动垃圾回收处理不可达对象。三色标记可用于理解追踪过程：白色表示尚未访问，灰色表示自身已访问但引用尚未全部处理，黑色表示引用已处理。

Lua 5.4 支持增量和分代两种回收模式；LuaJIT 及其他版本的具体实现与调参接口需要分别确认。可达但不再需要的缓存和事件引用仍须主动清理。
