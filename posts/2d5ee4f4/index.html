面试考点：计算机组成原理

发表于2025-12-10|更新于2026-11-13|计院八股文
|浏览量:

计算机硬件结构

  • 运算器：实现对数据的算术和逻辑运算
  • 控制器：取出并译码指令，发出控制信号，协调各部件工作
  • 存储器
    • 内部存储器：容量小、速度快、存放临时数据
    • 外部存储器：速度慢、长期存储
  • 输入设备
  • 输出设备

CPU

功能：实现程序控制、操作控制、时间控制、数据处理功能

  • 运算器
  • 控制器
  • 寄存器
  • 内部总线

运算器

功能：执行所有的算术运算；执行所有的逻辑运算并进行逻辑测试

  • 算术逻辑单元 ALU：实现对数据的算术和逻辑运算
  • 累加器 AC：运算结果或操作数存放区
  • 数据缓冲寄存器 DR：暂时存放内存的指令或数据
  • 状态条件寄存器 PSW：保存指令运行结果的条件码内容，如溢出标志等

控制器

功能：控制整个 CPU 工作，包括程序控制、时序控制等

  • 指令寄存器 IR：暂存 CPU 正在执行的指令
  • 程序计数器 PC：存放指令执行地址
  • 地址寄存器 AR：保存当前 CPU 访问的内存地址
  • 指令译码器 ID：分析指令操作码

指令和运算

计算机指令

组成：指令 = 操作码 + 操作数
操作码决定要完成的操作；操作数指参与运算的数据及其所在单元地址。
操作要求和操作数地址都用二进制数码表示，分别称为操作码和地址码。
整个指令都以二进制编码的形式存放在存储器中。

计算机指令执行过程

  1. 取指令：将 PC 中的指令地址取出，送入地址总线，CPU 根据指令地址去内存中取出指令内容存入 IR。
  2. 分析指令：ID 进行分析，分析指令操作码。
  3. 执行指令：读取所需操作数，完成运算、访存或控制转移，并写回结果。

指令集

指令集是处理器架构规定的机器指令集合；编译器、汇编器和链接器生成使用这些指令的程序，不会生成指令集本身。

常见指令集：

  • 算术指令集
  • 数据传输类指令
  • 逻辑类指令
  • 条件分支类指令
  • 无条件跳转指令

寻址方式

指令寻址方式

  • 顺序寻址方式：当执行一段程序时，是一条指令接着一条指令执行的。
  • 跳跃寻址方式：下一条指令地址码不是由程序计数器给出，而是由本条指令直接给出，程序跳跃后，按新的指令地址开始顺序执行。因此程序计数器的内容也必须相对应改变，以便及时更新新的指令地址。

指令操作数寻址方式

  • 立即寻址方式：指令的地址码指出的不是地址，而是操作数本身。
  • 直接寻址方式：在指令的地址字段中指出操作数在主存中的地址。
  • 间接寻址方式：指令地址码字段所指向的存储单元中存储的是操作数的地址。
  • 寄存器寻址方式：指令中的地址字段为寄存器编号。

指令系统

指令系统类型 指令特征 寻址方式 实现方式 其他
CISC 数量多，使用频率差别大，可变长格式，兼容性强 支持多种 微程序控制技术 研制周期长
RISC 数量少，使用频率接近，定长格式；大部分为单周期指令，操作寄存器，只有 Load/Store 操作内存 支持方式少 增加了通用寄存器，硬布线逻辑控制为主，适合采用流水线 优化编译，有效支持高级语言
  • CISC（复杂指令集计算机）：以 x86 为常见例子，指令编码和操作形式较丰富。
  • RISC（精简指令集计算机）：以 ARM、RISC-V 为常见例子，强调较规则的指令设计。具体性能还取决于微架构、编译器与工作负载。

指令流水线

原理：将指令分成不同段，每一段由不同的部分去处理，因此可以产生叠加的效果，所有的部件处理指令的不同段。

指令流水线示意图

0 1 2 3 4
取指 k+2 分析 k+2 执行 k+2
取指 k+1 分析 k+1 执行 k+1
取指 k 分析 k 执行 k

流水线计算

  • 流水线周期：指令分为不同执行阶段，其中执行时间最长的段为流水线周期。
  • 流水线执行时间：1 条指令总执行时间 + (总指令条数-1) * 流水线周期
  • 流水线加速比：不使用流水线总执行时间 / 使用流水线总执行时间

超标量流水线技术

标量处理器通常每周期至多发射一条指令；超标量处理器允许每周期发射多条指令。

理想情况下，宽度为 m 的超标量处理器每周期最多发射 m 条指令；实际吞吐量受数据依赖、分支与执行资源约束，不能直接将指令条数除以 m。

处理器运行原理

控制器从内存中取指令，解析指令，然后交给运算器运算执行，最后保存到内存。

计算机架构

冯诺依曼架构

指令存储器和数据存储器合并在一起。

  • 常用于 PC 处理器；
  • 指令和数据存储在一起；
  • 指令和数据通过相同的总线传输，这里强调共享访存通路，不按固定总线条数区分；

哈佛架构

程序指令和数据分开存储在两个独立的存储空间中，每个存储器都有独立编址、独立访问、是一种并行体系结构

  • 常用于嵌入式系统处理器；
  • 指令和数据分开存储，可同时并行读取，吞吐量高；
  • 指令和数据通过不同的总线传输，具体总线组织取决于实现；

CPU 运行逻辑

CPU(中央处理器)是计算机的核心部件，负责执行程序指令和处理数据。

  1. 指令的提取(Fetch)
    • CPU 从存储器中取出下一条要执行的指令，并将其放入指令寄存器中。
    • 通过 PC 实现的，PC 中存储了当前指令的地址，每次执行完一条指令后，PC 的值会自动更新为下一条指令的地址
  2. 指令的解码(Decode)
    • CPU 对指令寄存器中的指令进行译码，解析出指令类型、操作码和操作数等信息。
    • 解码后，CPU 将操作数送到控制单元，操作数则送到 ALU 或寄存器中准备执行。
  3. 指令的执行(Execute)
    • 在控制单元的协调下，CPU 的运算单元(ALU)对操作数进行算术运算或逻辑运算。
    • 执行过程中，可能需要从内存中读取数据或向内存写入结果。
  4. 结果的写回(Writeback)
    • 执行完指令后，运算单元将结果写回寄存器或内存中。
    • 如果指令涉及条件跳转或循环等操作，控制单元会根据指令的执行结果更新程序计数器的值，以指向下一条要执行的指令。

缓存机制

缓存用于暂时存储CPU频繁访问的数据和指令，

  • 现代 CPU 为了提高运行效率，通常引入了缓存(Cache)机制。
  • 缓存分为：一级缓存(L1 Cache)、二级缓存(L2 Cache)等。
  • CPU 执行指令时，优先从缓存中查找数据和指令，以减少对内存的访问次数，从而提高运行效率。

多核和超线程技术

  • 现代 CPU 多采用多核设计，每个核心可以独立执行指令。
  • 一些 CPU 还支持超线程技术(Hyper-Threading)，通过模拟多个逻辑 CPU 来同时执行多个线程，进一步提高 CPU 的并行处理能力。

总线和接口

  • CPU 通过总线、内存、I/O 设备等进行通信。
  • 总线分为
    • 地址总线：传输地址信息
    • 数据总线：传输数据信息
    • 控制总线：传输控制信息
  • CPU 与外设之间的通信通过接口电路来实现。

从内存读取高速缓存的数据是一小块一小块的，而不是按照单个数组元素来读取的。
CacheLine(缓存块)：一小块一小块的高速缓存数据；许多处理器采用 64 字节，具体大小取决于架构。

存储系统

采用分级存储目的：解决存储容量、成本和速度之间的矛盾问题

两级存储

Cache - 主存
主存 - 辅存(虚拟存储体系)

局部性原理

  • 局部性原理：CPU 运行时，所访问的数据会趋向于一个较小的局部空间地址内
    • 时间局部性原理：如果一个数据项正在被访问，那么它近期很可能被再次访问，即在相邻的时间里会访问同一个数据项。
    • 空间局部性原理：在最近的将来会用到的数据的地址和现在正在访问的数据地址可能是相近的，即相邻的空间地址会被连续访问。

高速缓存 Cache

地址映射：在 CPU 工作时，送出的是主存单元地址，而应从 Cache 存储器中读/写信息。这就需要将主存地址转换为 Cache 存储器地址，这种转换称之为地址映射，由硬件自动完成映射。

  1. 直接映射：Cache 和主存等分成块并编号，两个的对应关系是固定的，主存块按块号对 Cache 行数取模定位，并通过标记判断是否命中。地址变换简单，但不灵活，易造成资源浪费。
  2. 全相联映射：Cache 和主存等分成块并编号，主存中任意一块和 Cache 中任意一块对应。因此可以随意调入 Cache 任意位置，但地址变换复杂，速度较慢。最不易发生块冲突的映射方式。
  3. 组相联映射：Cache 和主存先分块再分组，组间采用直接映射，组内采用全相联映射。
